# Product and design docs

- `PRD.md` is technology-neutral (D-13): product behaviour only. Technical choices go in
  `docs/11-technical-decisions.md` as new `TD-xx` rows (mark superseded rows, never renumber).
- Requirement IDs are stable; add new IDs instead of renumbering. Record product decisions
  as `D-xx` in the PRD decision log and bump the PRD version in its change history.
- Only state facts that are sourced in `docs/02-algeria-research.md` (VERIFIED/ANNOUNCED).
- Never mention or associate the project with any other company product.
